# Навигация открытых страниц после входа

Исправлены `/about`, `/rules`, `/privacy`, `/consent`. Сервер проверяет существующую сессию до формирования HTML: участнику показывает «В ленту» со ссылкой `/app#/feed`, гостю — «Войти». На странице «О Dorm Hub» основная кнопка участника — «Открыть объявления». Ссылка возврата из документов также ведёт в ленту.

Проверка выполняется по действующей серверной сессии, а не по параметру URL или наличию произвольной cookie. Страницы остаются открытыми для гостей. Настройка техработ, согласия, тексты правил/политики и схема базы не меняются.

Проверены все четыре страницы с действующей, отсутствующей и неверной сессией, запросы HEAD, отсутствие кэширования и изменения cookie. Все Go-тесты с `-race` и `go vet ./...` прошли. Визуальная проверка реального браузера здесь не выполнялась.

Архив предназначен для текущей версии проекта после последних исправлений. Скачай `dorm-hub-public-navigation-fix.zip` в «Загрузки». На Mac:

```bash
cd ~/Desktop/projects/dorm-hub &&
unzip -o ~/Downloads/dorm-hub-public-navigation-fix.zip -d . &&
git add internal web tests docs &&
git commit -m "Fix public page navigation for signed-in users" &&
git push
```

После успешного GitHub Actions обнови открытые вкладки документов. Техработы сохранятся.
