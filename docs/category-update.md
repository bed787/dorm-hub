# Категории и новая лента

## Что изменилось

- Семь категорий: Техника, Одежда и обувь, Аксессуары, Для дома, Книги и пособия, Услуги, Другое.
- На главной — горизонтальные ряды с компактными карточками. Больше объявлений — выше ряд; пустые категории скрыты, «Другое» в конце.
- В рядах смешиваются новые и более старые активные объявления с учётом разных авторов. Порядок сохраняется при переходе в объявление и обратно.
- «Смотреть все» открывает категорию по дате. Поиск сохраняет сортировку по соответствию запросу. «Все новые» показывает общую ленту по дате.
- Создание: категория → поля, фотографии и контакты → предпросмотр. Отправка по-прежнему требует ручной модерации.
- Вместо двух выборов местоположения — одно общежитие. Группа определяется автоматически. Для «Другой адрес» адрес необязателен.

| Место в фильтре | Общежития |
|---|---|
| ПУНК | 10, 12–16, 20–23 |
| Халтурина | 8, 9 |
| ВШМ | 11 |
| Васильевский остров | 1–5, 17–19 |
| Солидарности | 6 |

## Старые объявления

При первом запуске автоматически применяется миграция `010_categories_and_locations.sql`.
Она сохраняет объявления, фотографии, ID и статусы. Прежние общие категории
«Вещи и техника» и «Жильё» переходят в «Другое»: точно определить новую категорию
по одному старому значению нельзя.

Открой **Модерация → Категории**, нажми **Изменить категорию** на карточке.
Объявление исчезнет из списка распределения, но сохранит свой статус.
Категорию можно исправить и из открытого объявления. Поисковый индекс обновится
через существующую очередь Meilisearch.

Общежития 8, 9 и 11 автоматически переносятся из старой общей группы в Халтурина
и ВШМ; номера и ID общежитий сохраняются.

## Локальная проверка на Mac

Архив содержит изменённые и новые файлы, с папкой `dorm-hub` внутри.
Если в локальной базе есть нужные данные, сохрани её копию перед первым запуском:
миграция меняет категории.

```bash
unzip -o ~/Downloads/dorm-hub-categories.zip -d ~/Desktop/projects
cd ~/Desktop/projects/dorm-hub
docker compose --env-file /dev/null -f compose.yaml up -d --build
```

Сайт: http://localhost:8080. Тестовые письма: http://localhost:8025.
Обычная тестовая почта: `student@students.example`, администратор: `admin@students.example`.
Если локальные настройки уже изменены, используй свои разрешённые адреса.
Режим технических работ хранится в базе и сохраняется после обновления.

Проверь ряды и «Смотреть все», создание и возврат между шагами с фотографиями,
предпросмотр, отправку на модерацию, фильтр ПУНК и распределение старых объявлений.
Ничего отправлять в GitHub для локальной проверки не нужно.
