# Логи в админке

Открой «Модерация» → «Логи». Раздел доступен только администратору, в том числе во время технических работ.

## Что видно

- Время события, уровень INFO/WARN/ERROR и сообщение приложения.
- Для HTTP-запроса: метод, шаблон маршрута, статус, длительность и ID запроса. Сами адреса с параметрами, тела запросов и cookie не копируются.
- Ошибки API и паники — с типом ошибки и ID запроса. Произвольные тексты ошибок, почты, токены и неизвестные атрибуты в веб-копию не включаются.

Поиск ищет буквальный текст в сообщении и деталях. Можно вставить ID запроса. Фильтр «Предупреждения и ошибки» включает WARN и ERROR. Поиск ограничен 200 символами.

Автообновление происходит раз в 5 секунд. Сними галочку, чтобы читать без обновлений, или нажми «Обновить». При переходе из раздела и выходе из аккаунта опрос прекращается. Успешные запросы просмотра логов не записываются в сам журнал.

## Что хранится

Последние 500 сообщений текущего процесса; на экране — до 200 самых новых совпадений. Старые события вытесняются. После перезапуска или обновления приложения буфер очищается. В базу этот журнал не записывается.

Обычный вывод приложения в Docker сохранён. Эта панель не читает журналы PostgreSQL и Caddy. Если приложение не запускается, сама админка также недоступна: ошибки запуска тогда смотри через `docker logs dorm-hub-app-1`.

## Обновление

Архив содержит текущие исправления логотипа/входа и журнал приложения. Настройки окружения, контакты в `web/site.json`, фотографии и база не заменяются. Новых миграций и серверных команд установки нет.

Скачай `dorm-hub-admin-logs.zip` в «Загрузки». На Mac:

```bash
cd ~/Desktop/projects/dorm-hub &&
unzip -o ~/Downloads/dorm-hub-admin-logs.zip -d . &&
rm -f web/assets/brand.png &&
git add internal web tests docs deploy/README.md .github/workflows/deploy.yml &&
git add -f .dockerignore &&
git commit -m "Add application logs to admin panel" &&
git push
```

Дождись успешного GitHub Actions. Режим техработ и его причина сохранятся.

## Проверка

- 40 тестов Node: в том числе экранирование сообщений, смена фильтра во время запроса, прекращение обновлений после ухода и отказа доступа.
- Все Go-тесты с `-race`, включая кольцевой буфер, параллельные записи, отбор атрибутов, API-доступ гостя/участника/администратора, отзыв роли и доступ во время техработ.
- `go vet ./...`, разбор CSS и синтаксис JavaScript.
- JSDOM с реальным HTTP, изолированной БД и тестовым SMTP: вход, загрузка журнала, фильтр WARN, поиск и переход в другой раздел. Полноценная визуальная проверка Chrome/Safari на телефоне здесь не выполнена.
