# Журнал приложения

Раздел «Модерация → Логи» доступен администратору, в том числе во время
технических работ. API: `GET /api/admin/logs?level=WARN&q=...`.

Журнал хранит последние 500 сообщений текущего процесса в памяти и возвращает
до 200 новых совпадений. После перезапуска буфер очищается. Постоянные логи
контейнера доступны отдельно через Docker.

Для HTTP-запросов записываются метод, шаблон маршрута, статус, длительность и
ID запроса. В веб-копию не включаются тела запросов, cookie, коды входа,
произвольные тексты ошибок и неизвестные атрибуты. Отбор полей реализован
в `internal/platform/logview`.

Поиск — буквальный, до 200 символов. Фильтр WARN включает предупреждения и ошибки.
Автообновление выполняется раз в 5 секунд и прекращается при уходе из раздела
или потере доступа. Успешные запросы просмотра логов не записываются в этот журнал.

Панель не читает журналы PostgreSQL и Caddy. Если приложение не запускается,
его вывод можно посмотреть на сервере:

```bash
docker logs --tail=100 dorm-hub-app-1
```
