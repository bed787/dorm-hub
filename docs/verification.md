  отказ с комментарием и исправление; одобрение; открытие редактора без правок
  сохраняет публикацию; завершение и общий счётчик; удаление с отдельным кодом.
- Серверные проверки: приватность pending/archived и фото; запрет чужих правок;
  устаревшая ревизия модератора; изменение фото снимает публикацию; завершённое

  удаление очищает данные и фото, сохраняя только общий итог; отдельный код,

  не восстанавливает удалённый аккаунт.
- HTML-ссылки на ресурсы, SQL-миграция 004 и конфигурации проверены при запуске.

## Проверка у себя

```bash
docker compose -f compose.test.yaml up --abort-on-container-exit --exit-code-from tests
docker compose -f compose.test.yaml down
node --test tests/*.test.cjs
```

Затем запусти основной Compose и проверь в браузере на компьютере и телефоне:

1. У участника без контактов профиля создать объявление, ввести контакт в форме,
   добавить фото, отправить на проверку. У другого участника запись не видна.
2. Администратор открывает очередь, проверяет контакты/фото, возвращает с причиной.
   Автор находит запись в архиве, исправляет и отправляет заново.
3. После одобрения запись видна; текстовые и фото-правки снова скрывают её.
   Устаревшее одобрение во второй вкладке получает 409.
4. Незаконченная форма сохраняется в архив. Проверить переходы, перезагрузку,
   временное отключение сети и сохранение выбранных фото.
5. Успешное завершение увеличивает итог, повтор за то же объявление — нет,
   «больше не актуально» не учитывается.
6. Удалить аккаунт отдельным кодом. Проверить отсутствие профиля, публикаций,
   фотографий и отзыв всех сессий. Повторный вход создаёт новый аккаунт.
7. Логотип увеличен до 96×88 в шапке и 132×120 на входе; мобильные размеры
   76×70 и 104×96. На узких экранах шапка скрывает текст бренда и счётчик.


## Исправление доступа по локальной сети — 14 октября 2026

- Вместо буквального сравнения Origin используется сравнение HTTP(S)-источников
  с нормализацией стандартных портов.
- В development разрешён фактический Host запроса, только для localhost и
  private/loopback/link-local IP. Это позволяет переключаться между LAN и localhost.
- В production допустим только настроенный BASE_URL.
- Тесты проверяют LAN, IPv4/IPv6 loopback, чужой сайт, другой IP/порт, отсутствие
  Origin, null Origin, public IP, подставные forwarded-заголовки и production.
- HTTP-обёртка проверена отдельно: допустимый LAN-запрос проходит, отсутствие CSRF
  и чужой Origin отклоняются, даже если второй запрос содержит правильный токен.
- Реальная сеть пользователя недоступна; точная причина исходного несовпадения
  Origin и BASE_URL не установлена. Изменение исправляет излишнюю привязку
  локальной разработки к единственному адресу.
