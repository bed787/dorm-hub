# Dorm Hub

Доска объявлений для студентов СПбГУ: продажа и обмен вещей, услуги и поиск помощи.
Проект работает в production на [dorm-hub.ru](https://dorm-hub.ru). Объявления,
профили и контакты доступны после входа по коду из письма.

Сервер написан на Go с `net/http` и `pgx`. Данные хранятся в PostgreSQL,
полнотекстовый поиск работает через Meilisearch с резервным поиском в PostgreSQL.
HTML, CSS, JavaScript и SQL-миграции встроены в бинарник через `embed`.

## Возможности

- Объявления с фотографиями, категориями и фильтрами по местоположению.
- Черновики с автосохранением, ручная модерация и комментарии при отказе.
- Избранное, профили, жалобы и управление доступом к площадке.
- Статистика использования, журнал приложения и мониторинг через Prometheus/Grafana.

## Серверная часть

Один сервис обслуживает API и интерфейс. Код разделён по предметным областям:
`auth`, `users`, `listings`, `media`, `moderation`, `analytics`.

- Изменения объявления проверяют `revision`: устаревшая правка или решение
  модератора возвращает конфликт. Лимиты публикаций и фотографий проверяются
  внутри транзакций с блокировками.
- Создание объявлений и загрузка фото поддерживают ключи идемпотентности.
- Поисковый индекс обновляется через очередь в PostgreSQL. Выдача повторно
  проверяется в БД, чтобы скрытые и устаревшие объявления не попадали в результат.
- Удаление аккаунта очищает связанные записи в транзакции; удаление файлов
  проходит через очередь с повторами при ошибке диска.
- Сессии хранятся на сервере. Изменяющие запросы проходят проверки Origin и CSRF.

Подробнее — в [описании архитектуры](docs/architecture.md) и [справочнике API](docs/api.md).

## Локальный запуск

Нужен Docker с Compose:

```bash
docker compose up -d --build
```

| Адрес | Назначение |
|---|---|
| http://localhost:8080 | Приложение |
| http://localhost:8025 | Mailpit с кодами входа |

Тестовые адреса: `student@students.example` и `admin@students.example`.
Код входа приходит в Mailpit. Значения для разработки заданы в `compose.yaml`;
при необходимости их можно переопределить в локальном `.env`.

```bash
docker compose down
```

Остановка сохраняет базу и фотографии. Флаг `-v` удаляет тома с данными.
Миграции применяются автоматически при запуске приложения.

## Проверки

JavaScript:

```bash
node --test tests/*.test.cjs
```

Go, PostgreSQL и Meilisearch в отдельном тестовом окружении:

```bash
docker compose -f compose.test.yaml up --abort-on-container-exit --exit-code-from tests
docker compose -f compose.test.yaml down
```

Для установленного Go версии из `go.mod`:

```bash
go vet ./...
go test -race ./...
go build -o bin/dorm-hub ./cmd/api
```

Интеграционные Go-тесты требуют `TEST_DATABASE_URL` с именем базы, оканчивающимся
на `_test`. Они очищают эту базу; без переменной пропускаются. Для проверки
настоящего поискового движка также нужны `TEST_MEILI_URL` и `TEST_MEILI_MASTER_KEY`.
